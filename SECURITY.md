# Security policy

This repository is pre-alpha and contains no SDK functionality yet (see `LIMITATIONS.md`).

To report a vulnerability, please use GitHub's **private vulnerability reporting**
(the "Report a vulnerability" button under this repository's *Security* tab). Do not open a
public issue for security problems.

Scope notes for later releases:

- Publishing Solidity source does not verify any deployed contract, yours or ours.
- Build provenance (for example npm provenance) links an artifact to a build. It is not an audit.
