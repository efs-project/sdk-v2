# @efs/sdk

**Pre-alpha. This package contains no SDK functionality yet.**

It is the portable TypeScript SDK for EFS v2, for browsers, Workers, Node servers,
scripts and JavaScript agent harnesses. The repository is at its initialization
stage (S0). The only exports are clearly marked placeholders that prove the
build, exports map and packed-consumer checks work. They are listed in
[`LIMITATIONS.md`](../../LIMITATIONS.md) and will be removed by the first feature work.

The package is `private` and is not published.
